# MR JOO COMMANDER

وكيل بناء برامج بتتحكم فيه إنت: هو بينفّذ، وإنت بتوافق أو ترفض.
من غير أي مكتبات خارجية (لا npm install ولا حاجة).

## تشغيل
1. `cp .env.example .env` وحط `ANTHROPIC_API_KEY` (أو حطه في Secrets).
2. `npm start`
3. افتح الرابط، واكتب رمز الدخول اللي ظهر في الكونسول.

## التحكم
- **عادي**: بيكتب ويعدّل لوحده، ويستأذنك في الحذف والنشر والرفع.
- **صارم**: بيستأذنك في كل كتابة كمان.
- كل طلب موافقة بيظهر كارت فيه ✅ / ❌ وتفاصيل اللي هيتنفذ.

## الإمكانيات
بناء مشاريع، تعديل دقيق (edit_file)، نسخ احتياطي واسترجاع، Project Doctor (فحص أخطاء ومكتبات ناقصة ومفاتيح مكشوفة)، معاينة حية، مستشارين Gemini/GPT، GitHub، Vercel، دفتر أرباح، تليجرام.

## أمان
- الرمز مطلوب لكل شيء. المعاينة برابط سري ومعزولة (sandbox).
- المفاتيح في .env/Secrets بس ومبتظهرش للمتصفح ولا للوكيل.
- النشر والرفع بيتوقفوا لو لقوا مفتاح سري جوه الكود.
